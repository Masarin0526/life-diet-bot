# Life Diet BOT

A LINE chatbot that supports healthy eating habits with the help of cute AI characters.

## Setup

1. Clone this repository
2. Install dependencies: `pip install -r requirements.txt`
3. Create `.env` file based on `.env.sample`
4. Run locally: `python main.py`
5. Deploy on Vercel and set webhook to `/callback`

## Characters
- Carona: Cheerful and supportive
- Treo: Cool and calm
- Pekoru: Cute mascot style
